# Пакком — Радар

Управленческий дашборд. Рабочая страница: `index.html` в ветке `main`.

## Правила обновления

Новые периоды добавляются в существующую актуальную версию. Не генерировать заново интерфейс, фильтры, формулы и исторические записи. Сначала читать текущую версию `main`, чтобы не затереть доработки из другого чата. Повторную загрузку идентичного периода пропускать; конфликт с закрытыми датами останавливать и разбирать отдельно.

Технические описания источника, обновления и сверки, служебный CONTROL не выводить на рабочий экран. Внутренние проверки данных, дату актуальности и управленческие статусы CPO сохранять. Скрытие служебных блоков не означает, что неустранённые расхождения проверены или исправлены.

## Защита от повторного разделения SKU

`1721217247` и `1721217247.0` — один идентификатор. Единый нормализованный ключ применять к группировке, поиску, раскрытию карточки и сигналам. Поиск должен учитывать `x`, `х`, `×` между цифрами, регистр и повторные пробелы.

Регрессионные примеры:
- пакеты рулон 30х40 100 шт бел пищевые — `1721217247`;
- пакеты крафт 195х90х340 v-дно 50 шт — `1556365321`.

Не объединять разные артикулы по похожему названию. Недостающие идентификаторы сопоставлять только по подтверждённому справочнику.
