# Оценочная экономика 12–15.11.2026

Основание — пользовательский запрос показать на постоянных сайтах расчёты из `Пакком_ОЦЕНКА_ЧП_12-15.11.2026.xlsx` (SHA-256 `cf4e60942b438a0bf6b78dc378842ea5d65ed28c560ebc2181e70b514fc348f5`). Период операционных данных остаётся по 15.11; финансовая история закрыта только по 11.11.

`estimate-view-v1.js` хранит модель отдельно в DATA.estimatesV1. Нельзя переносить прогноз в поля profit/payout/vat/cost исторического DATA.daily. При получении фактической детализации сначала сверить и закрыть дни, затем отметить/обновить статус оценки. Не складывать календарную оценку прибыли выкупов и будущий результат заказов.

Приватные значения находятся только в `data/management-estimates-20261115.json` (RSA-OAEP/AES-GCM + gzip, прежний publicKey). Новый payload добавлен в конец существующей цепочки, account/basePayload/предыдущие обновления не изменены. Публичный `data/radar-estimates-20261115.json` содержит только существующие операционные показатели, оценочные пределы CPO и сигналы/действия, без сумм ЧП, себестоимости и калибровочных коэффициентов.

Модель включает 257 SKU, отдельные сценарии 80/90/95% будущего выкупа, чувствительность выплаты ±5%, маркировку оценочного статуса. Это не доверительный интервал и не основание автоматически удалить ассортимент или увеличить рекламу. CPO рассчитывается от всех заказов SKU.

Обозначения и названия взяты из Excel. Существующая SKU identity v4 не менялась; проверка расчётного регистра использует WB ID, а для строк без ID — точное нормализованное имя с утверждённым правилом отдельного кириллического НГ. Размер/объём/фасовка/рисунок сохраняются.

Новый блок имеет собственные поиск/группу/фильтры/сортировку и фиксированный период 12–15.11. Основная история и её фильтры не заменены. Оперативный слой скрытия отсутствующей фактической ЧП не скрывает отдельный блок оценки.

Проверки: `node tests/estimate-view-v1.cjs`, `node tests/lightweight-loaders-v2.cjs`, `node tests/operations-update-v1.cjs`. Проверки входа выполняются только на синтетических ключах. Для публикации обязательны SUCCESS Pages и `node tests/lightweight-loaders-v2.cjs --live` с побайтной сверкой обоих постоянных адресов и зависимостей.
