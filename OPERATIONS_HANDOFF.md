# Оперативное обновление по 15.11.2026

Финансовый контур закрыт только по 11.11.2026. По просьбе пользователя 12–15.11 добавлены без расчёта прибыли, НДС, себестоимости, выплаты и выручки по реализации. Эти поля отсутствуют (null), а не равны нулю.

Источники: report_2026_11_16.xlsx.XLSX и история рекламных затрат 11–15.11.2026. Количество продаж в оперативном режиме — поле «Выкупили, шт.» из report, без отдельной сверки возвратов по детализированным финансовым отчётам. ordersNetRub берётся напрямую из report, ordersRub = ordersNetRub / 0.70. ДРР = реклама / ordersRub.

11.11 пересекается с историей: свежий report уточнил заказы с 3764 до 4535, исходную сумму с 865904.07 до 1042816.13. Выкупы 3347 и реклама 83061 совпали по SKU. 11.11 заменён один раз, финансовые значения сохранены.

Оба корневых загрузчика сохраняют прежние интерфейсы и базы. operations-update-v1.js применяет проверенный компактный регистр и скрывает недоступную финансовую аналитику только для незакрытого диапазона. Публичный регистр: data/operations-20261115.json, gzip + SHA-256. Приватный эквивалент: data/management-operations-20261115.json, прежние RSA-OAEP/AES-GCM и текущий account.publicKey. Account, basePayload и предшествующие зашифрованные обновления сохранены.

Нельзя добавлять последующие финансовые обновления как новые строки за 12–15.11 поверх оперативных. Сначала сверить соответствующие date × canonical SKU, затем заменить недоступные поля подтверждёнными финансовыми данными, сохраняя уточнённые заказы и рекламу. Не отключать проверки схемы/дат/сумм и не заменять null на 0.

Контроль новых дней 12–15.11: 15227 заказов, 13178 выкупов по report, 339640 рублей рекламы. По всей новой выгрузке 11–15.11: 19762 заказа, 16525 выкупов и 422701 рублей рекламы. Распределены 119 кампаний Пакком, включая 9 кампаний пластиковых пакетов. Несопоставленные с ассортиментом Пакком кампании отдельно сохранены в Excel, а не распределены приблизительно.
