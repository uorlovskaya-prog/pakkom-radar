# Пакком — склад

Отдельная открытая управленческая панель выработки фасовщиц.

Публикация: https://uorlovskaya-prog.github.io/pakkom-radar/sklad/

Папка `sklad/` изолирована от главной панели «Радар». Файлы `index.html` в корне, `sku-identity-v4.js` и существующие рабочие процессы не изменяются.

## Правила расчёта

- Выработка за 14–30 сентября 2026: 38 150 готовых упаковок, 3 533 исходные строки.
- Нормативное время = количество готовых упаковок × секунд на упаковку; это не фактическое время присутствия.
- Среднее за рабочий день = нормативное время сотрудницы / число её дат с выработкой. Совпадение дат с другой сотрудницей не требуется.
- Пустая дата означает отсутствие записи, а не нулевую выработку или подтверждённый невыход.
- Нормы: согласованный мастер от 29.09.2026 с последними утверждёнными уточнениями владельца. Исходные WB и неуточнённые имена сохраняются.
- Данных за 1–13 сентября нет. Складские остатки, движения, Airtable, production и staging эта панель не изменяет.

Обновления публикуются отдельно от «Радара», после проверки входных данных. Сайт не получает новые записи автоматически.
